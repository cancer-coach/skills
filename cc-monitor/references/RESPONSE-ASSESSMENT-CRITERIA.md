# Response Assessment Criteria

## RECIST 1.1

### Target Lesion Rules
- Max 5 target lesions (max 2 per organ)
- Measurable: ≥10mm on CT, ≥15mm for lymph nodes
- Measure longest diameter (short axis for nodes)

### Response Categories
| Category | Definition |
|----------|-----------|
| CR | All targets disappear, lymph nodes <10mm |
| PR | ≥30% decrease from baseline sum of diameters |
| SD | Neither PR nor PD |
| PD | ≥20% increase from nadir AND ≥5mm absolute increase, or new lesions |

### Timing
- Baseline: within 4 weeks before treatment
- Assessment: every 6-12 weeks during treatment
- Response: compare to baseline
- Progression: compare to nadir

## iRECIST

### Why Different
Immunotherapy causes pseudoprogression, delayed responses, new lesions that later resolve, immune flare.

### Modified Categories
| Category | Definition | Action |
|----------|-----------|--------|
| iCR | Complete response | Confirm at next scan |
| iPR | ≥30% decrease | Confirm at next scan |
| iSD | Neither iPR nor iUPD | Continue treatment |
| iUPD | Meets PD criteria | MUST confirm 4-8 weeks later |
| iCPD | Confirmed progression | True treatment failure |

**Rule**: Never abandon immunotherapy based on a single scan.

## PERCIST (PET)

| Category | SUV Change |
|----------|-----------|
| Complete metabolic response | No FDG uptake above background |
| Partial metabolic response | ≥30% SUV decrease |
| Stable metabolic disease | <30% change |
| Progressive metabolic disease | ≥30% SUV increase or new lesions |

## Choi Criteria (GIST/Sarcoma)
Considers size AND density on CT. Tumor becoming more cystic = responding, even without size change.

## Pathologic Response

| Grade | Definition |
|-------|-----------|
| pCR | No viable tumor cells |
| MPR | ≤10% viable tumor |
| Partial | 10-50% viable |
| None | >50% viable |
